## 推荐的学习方式

1. 按 [学习路线](/roadmap) 的阶段顺序推进，每读完一篇文章、做完一个项目就标记为 **已完成**，进度会保存在本地 SQLite 数据库中。
2. 每个知识点先读文章 → 打开对应实战项目 → 在工作台里 **仿真** → 有硬件再 **烧录** 到实物上。
3. 遇到问题先查 [排障手册](/troubleshooting)，再把心得记在 **笔记** 里。

## 功能地图

| 模块 | 作用 |
| --- | --- |
| 学习路线 | 8 个阶段，从零到能独立做项目 |
| 知识库 | 按分类组织的文章，支持文中嵌入电路图 |
| 物料库 | 元件图鉴：参数、引脚、价格、选购与注意事项 |
| 实战项目 | 带接线图、代码、讲解的完整例子，一键复制到工作台 |
| 工作台 | 代码编辑 + 电路编辑 + 编译 + 仿真 + 烧录 + 串口，一站完成 |
| 电路编辑器 | 拖拽元件、连线，自动检查 LED 是否缺限流电阻 |
| 环境中心 | 一键安装 arduino-cli、芯片核心、库，查看驱动指引 |
| 串口监视器 | 收发串口数据，支持多种波特率 |
| 工具箱 | 欧姆定律、LED 限流电阻、分压、色环、单位换算、引脚图 |
| 排障手册 | 按驱动/烧录/编译/串口/电路/供电分类的常见问题 |

## 工作台流程

```
写代码 ──► 编译（后端 arduino-cli）──► 得到 .hex 固件
                                   │
               ┌───────────────────┴──────────────────┐
               ▼                                      ▼
     浏览器内仿真（仅 Uno）                  烧录到实物（选择串口）
     电路图上的 LED/蜂鸣器实时反应                     │
     串口输出显示在下方                               ▼
                                         串口监视器查看输出
```

## 数据存储

- 你的项目、学习进度、笔记都保存在本机 `~/.mcu-classroom/data.db`（SQLite）。
- 工具链安装在 `~/.mcu-classroom/toolchain`。
- 可以通过环境变量 `MCU_DATA_DIR` 修改位置。
