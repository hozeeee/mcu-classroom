## 一句话解释

**单片机（MCU，Microcontroller Unit）** 是把 CPU、内存（RAM）、程序存储（Flash）、定时器、输入输出引脚等全部集成在 **一颗芯片** 上的微型计算机。

你写的程序被烧录进芯片的 Flash，上电后从头执行，直接控制引脚的高低电平——从而点亮 LED、驱动电机、读取传感器。

## 和你熟悉的电脑/浏览器对比

| 概念 | 电脑 / Node.js | 单片机 |
| --- | --- | --- |
| CPU 主频 | 3 GHz 多核 | 16 MHz（Uno）~ 240 MHz（ESP32） |
| 内存 | 16 GB | 2 KB（Uno）~ 520 KB（ESP32） |
| 存储 | 1 TB SSD | 32 KB ~ 4 MB Flash |
| 操作系统 | Windows / macOS / Linux | 通常没有，程序直接跑在"裸机"上 |
| 程序入口 | `main()` / `index.js` | `setup()` 执行一次，`loop()` 无限循环 |
| 输入输出 | 键盘、屏幕、网络 | **GPIO 引脚**：直接输出 0V / 5V 电压 |
| 调试 | DevTools 断点 | 串口打印、LED 指示、逻辑分析仪 |

> 2KB 内存是什么概念？一个稍长的 JSON 字符串就能把它塞满。所以单片机编程更注重"省"。

## 单片机能做什么

- **智能家居**：温湿度计、智能插座、自动浇花
- **机器人**：小车、机械臂、无人机飞控
- **可穿戴**：手环、计步器
- **工业控制**：PLC、电机控制器
- **物联网**：把传感器数据上传到云端，或用手机远程控制

你身边的空调遥控器、电饭煲、键盘、鼠标、充电宝里面都有单片机。

## 单片机 vs 开发板 vs 树莓派

- **单片机**：只是一颗芯片，如 ATmega328P、ESP32、STM32F103。
- **开发板**：把芯片 + USB 下载电路 + 稳压 + 排针做成一块方便实验的板子，如 Arduino Uno。初学者买的都是开发板。
- **树莓派（4/5 代）**：是跑 Linux 的单板电脑，不算单片机；但 **树莓派 Pico** 是单片机开发板。

## 学单片机要学什么

1. **电子基础**：电压、电流、电阻，能看懂电路图（本站"电子基础"分类）。
2. **C/C++ 编程**：和 JS 语法很像，主要多了类型和指针（本站"程序编写"分类）。
3. **外设与协议**：GPIO、ADC、PWM、UART、I2C、SPI。
4. **工具使用**：编译、烧录、串口调试、万用表。

作为前端开发者，你已经具备了编程思维，**最大的门槛其实是电路**。别担心，从点亮一颗 LED 开始。
