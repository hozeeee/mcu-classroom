## 为什么要做 PCB

面包板接触不良、体积大、容易碰掉线。作品定型后，可以按以下顺序升级：

1. **洞洞板（万能板）**：手工焊接，适合一次性作品。
2. **PCB（印制电路板）**：画好设计文件交给工厂生产，5 片打样仅需几十元甚至免费。

## 工具选择

| 工具 | 特点 |
| --- | --- |
| **嘉立创 EDA（立创 EDA）** | 中文、免费、浏览器即可使用，元件库与嘉立创商城打通，下单方便。**新手首选** |
| **KiCad** | 开源免费、跨平台、功能专业，国际社区强大 |
| Altium Designer | 商业软件，企业常用 |

## 设计流程

```
原理图 ──► 元件封装 ──► PCB 布局 ──► 布线 ──► DRC 检查 ──► 导出 Gerber ──► 下单打样 ──► 焊接
```

1. **画原理图**：与"看懂电路原理图"一文中的符号一致。把面包板上验证过的电路完整画出来。
2. **选封装**：同一个电阻有直插（THT，如 AXIAL-0.4）和贴片（SMD，如 0805）。新手建议 **直插** 或 **0805 以上** 的贴片，方便手焊。
3. **布局**：先放接插件、开发板模块、按键这些位置固定的元件，再放其他元件。相关元件尽量靠近。
4. **布线**：
   - 信号线 0.25mm，电源线 0.5mm 以上，大电流线更粗。
   - 避免 90° 直角走线。
   - 底层大面积铺铜接 GND。
5. **DRC（设计规则检查）**：检查线距、孔径、未连接网络。
6. **导出 Gerber** 并上传到 PCB 厂商（嘉立创、JLCPCB、PCBWay 等）。

## 新手建议

- 第一块板子可以做成 **"扩展板"**：直接把 Arduino Nano / ESP32 / Pico 模块插在你的 PCB 上，不需要自己设计最小系统电路。
- 留出 **测试点** 和 **调试接口**（串口、SWD）。
- 板子四角留安装孔（M3）。
- 丝印上标清楚引脚名称和版本号，以后自己会感谢自己。
- 打样之前，把 PCB 按 1:1 打印到纸上，把元件放上去比对一下封装大小。

## 进阶：设计最小系统

想彻底摆脱开发板，需要自己设计芯片最小系统：电源（LDO + 去耦电容）、时钟（晶振 + 负载电容）、复位电路、下载接口（USB 转串口或 SWD）。可以参考开发板官方开源的原理图（Arduino、Raspberry Pi Pico 都公开了设计文件）。
