## 原理图 vs 接线图

- **接线图 / 实物图**：画出元件真实的样子和导线，直观但复杂电路会乱成一团。
- **原理图（Schematic）**：用标准符号表示元件，用线表示 **电气连接**，不关心实际位置。工程师交流全靠它。

本站的 [电路编辑器](/circuit) 介于两者之间：元件有接近实物的外观，同时清楚标出每个引脚的电气连接。

## 常见符号

| 元件 | 符号（文字示意） | 说明 |
| --- | --- | --- |
| 电阻 | `─[▭]─` 或锯齿线 | 标注阻值，如 R1 220Ω |
| 电容 | `─┤├─` | 电解电容一侧带 + 号 |
| 二极管 | `─▶|─` | 三角形指向为电流方向，竖线为阴极 |
| LED | `─▶|─` + 两个向外箭头 | 箭头表示发光 |
| 按键 | `─o  o─` 上方一个横杠 | 常开按键 |
| 电源 | `VCC` / `5V` / `3V3` / 向上箭头 | 同名的电源网络都是连在一起的 |
| 地 | `GND` / 三条递减横线 ⏚ | 所有 GND 都相连 |
| 芯片 | 矩形 + 引脚编号/名称 | 如 U1 ATmega328P |

## 连接规则

1. **交叉的线不一定相连**：只有在交点画了 **实心圆点** 才表示连接。
2. **网络标号（Net Label）**：两处写着相同名字的线（如 `SDA`）即使没画线也是连通的。
3. **元件编号**：R1、R2 是电阻，C 是电容，D 是二极管，LED 也常写 D，Q 是三极管，U 是芯片，J/P 是接插件。

## 从原理图到面包板

以"LED 闪烁"为例，原理图：

```
D13 ──[R1 220Ω]──▶|── GND
                 LED1
```

读法：D13 → R1 → LED1 阳极 → LED1 阴极 → GND。于是在面包板上：

1. 杜邦线从 Uno 的 D13 插到面包板第 10 列。
2. R1 一端插第 10 列，另一端插第 15 列。
3. LED 长脚插第 15 列，短脚插第 18 列。
4. 杜邦线从第 18 列接到 Uno 的 GND。

在电路编辑器中对应的图是这样的：

```circuit
blink
```

## 读模块原理图的技巧

买来的传感器模块通常会附带原理图，重点看：

- 模块的 **供电电压**（VCC 接 3.3V 还是 5V）
- 板上是否已有 **上拉电阻**、**限流电阻**
- 引脚的 **输出类型**（数字 DO / 模拟 AO）
