## 按输出类型分类

传感器是单片机的"感官"。读取方式只有几种：

| 输出类型 | 读法 | 例子 |
| --- | --- | --- |
| 数字开关量（DO） | `digitalRead()` | 按键、人体红外 PIR、霍尔开关、光敏模块 DO |
| 模拟电压（AO） | `analogRead()` | 电位器、光敏电阻、土壤湿度、LM35 |
| 脉冲宽度 | `pulseIn()` | HC-SR04 超声波 |
| 单总线协议 | 专用库 | DHT11/DHT22、DS18B20 |
| I2C | Wire 库 | MPU6050、BMP280、BH1750、OLED |
| SPI | SPI 库 | SD 卡、RC522 RFID |

## 光敏电阻（LDR）

光越强，电阻越小。与一个固定电阻组成分压电路，接到 ADC 引脚：

```cpp
int value = analogRead(A0);   // 0 ~ 1023
```

很多光敏模块同时有 **AO**（模拟）与 **DO**（数字，板载比较器 + 电位器调阈值）两种输出。

```circuit
light-sensor
```

## DHT11 温湿度

- 供电 3.3 ~ 5V，单根数据线，需要上拉（模块已带）。
- 精度：温度 ±2℃，湿度 ±5%，采样间隔 ≥ 1 秒。
- 想要更准确选 **DHT22** 或 **SHT30**（I2C）。
- 库：DHT sensor library（Adafruit）。

## HC-SR04 超声波

- TRIG 引脚给 10μs 高电平 → 模块发出 40kHz 超声波 → ECHO 引脚输出高电平，宽度等于往返时间。
- 距离（cm）= 高电平时间（μs） × 0.034 / 2。
- 测量范围 2 ~ 400cm，5V 供电。接 ESP32 时 ECHO 输出 5V，要分压。

## PIR 人体红外（HC-SR501）

- 检测到人体移动时 OUT 输出高电平，持续时间和灵敏度可用板上两个电位器调节。
- 上电后需要约 1 分钟稳定。

## MPU6050 六轴

- 三轴加速度 + 三轴陀螺仪，I2C 接口（地址 0x68）。
- 用于平衡车、姿态检测、计步。
- 原始数据有噪声，通常要配合互补滤波或卡尔曼滤波。

## 选型建议

1. 优先选 **模块**（带电路板、排针、上拉/稳压），不要买裸元件。
2. 注意 **供电电压** 与 **输出电平**，3.3V 主控尽量选 3.3V 模块。
3. 优先选 **I2C 数字接口** 的传感器，占用引脚少、精度高。
