## 面包板内部结构

面包板（Breadboard）是免焊接的实验板，内部是一排排金属弹片：

```
 + ─────────────────────────────  ← 电源轨（整条横向连通）
 - ─────────────────────────────
   1  2  3  4  5  6  7  8 ...
 a ●  ●  ●  ●  ●  ●  ●  ●     ┐
 b ●  ●  ●  ●  ●  ●  ●  ●     │ 每一 **列** 的 a~e 五个孔连通
 c ●  ●  ●  ●  ●  ●  ●  ●     │
 d ●  ●  ●  ●  ●  ●  ●  ●     │
 e ●  ●  ●  ●  ●  ●  ●  ●     ┘
   ════════ 中间凹槽（隔断）════════
 f ●  ●  ●  ●  ●  ●  ●  ●     ┐
 g ●  ●  ●  ●  ●  ●  ●  ●     │ f~j 五个孔连通
 h ●  ●  ●  ●  ●  ●  ●  ●     │（与上半部分不通）
 i ●  ●  ●  ●  ●  ●  ●  ●     │
 j ●  ●  ●  ●  ●  ●  ●  ●     ┘
 + ─────────────────────────────
 - ─────────────────────────────
```

关键点：

1. 中间区域：**同一列的 5 个孔相通**，中间凹槽两侧不通。
2. 两侧电源轨：**整行相通**，通常红线标 +，蓝线标 -。
3. 部分长面包板的电源轨在中间是 **断开的**，需要用跳线连起来——这是新手常见的坑。
4. 芯片/模块要 **跨在中间凹槽上**，这样每只引脚各占一列。

## 常见错误

| 错误 | 后果 |
| --- | --- |
| 元件两脚插在同一列 | 被短路，元件不起作用 |
| LED 和电阻没有共用一列 | 断路，LED 不亮 |
| 5V 和 GND 插到同一列 | **短路！** 板子发烫，电脑 USB 报过流 |
| 电源轨中间断开没跳线 | 一半的元件没电 |

## 杜邦线

| 类型 | 用途 |
| --- | --- |
| 公对公 | 面包板 ↔ Arduino 排母 |
| 公对母 | 面包板 ↔ 模块排针（如 DHT11 模块） |
| 母对母 | 模块 ↔ 带排针的开发板（ESP32、Blue Pill） |

## 整洁接线的习惯

- **颜色约定**：红色 = 电源，黑色 = GND，其他颜色 = 信号。本站电路编辑器也采用这一约定。
- 先接 **电源和地** 到电源轨，再接信号线。
- 尽量让元件和导线短而贴板。
- **改线之前先断电**。
- 接完线后对照电路图逐根检查一遍，再上电。

## 在电路编辑器中练习

本站的电路编辑器不模拟面包板孔位，而是直接画出元件之间的连接，作用相当于"接线清单"。实际搭电路时，按照编辑器里的连线逐根插到面包板上即可。
