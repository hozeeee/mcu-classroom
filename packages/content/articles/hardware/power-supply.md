## 开发板的电源引脚

以 Arduino Uno 为例：

| 引脚 | 方向 | 说明 |
| --- | --- | --- |
| USB | 输入 | 5V，电脑 USB 2.0 口最多约 500mA |
| DC 圆口 / VIN | 输入 | 7 ~ 12V，经板载 LDO 稳压到 5V |
| 5V | 输出/输入 | USB 或稳压后的 5V，可给模块供电；也可以从这里直接输入稳定的 5V |
| 3V3 | 输出 | 板载 3.3V 稳压，**只能提供约 50mA** |
| GND | — | 地 |

ESP32 DevKit：VIN（5V 输入）→ 板载 AMS1117 → 3V3。WiFi 发射峰值电流可达 500mA，供电不足时会触发 **Brownout 复位**。

## 稳压芯片

| 类型 | 例子 | 特点 |
| --- | --- | --- |
| 线性稳压 LDO | AMS1117-3.3、HT7333 | 简单、纹波小，但压差全部变成热量；效率 = Vout/Vin |
| 降压 DC-DC (Buck) | MP1584、LM2596 | 效率 85% ~ 95%，适合高压差大电流 |
| 升压 DC-DC (Boost) | MT3608 | 3.7V 锂电池升到 5V |

计算 LDO 发热：12V 转 5V、输出 200mA → 损耗 (12-5)×0.2 = 1.4W，AMS1117 会非常烫。

## 电池方案

| 电池 | 电压 | 说明 |
| --- | --- | --- |
| 3 节 AA 干电池 | 4.5V | 简单安全 |
| 18650 锂电池 | 3.0 ~ 4.2V | 容量大，需保护板与 TP4056 充电模块 |
| 9V 方块电池 | 9V | 容量很小，不推荐长期使用 |
| 充电宝 | 5V USB | 最省心；注意部分充电宝电流过小会自动关机 |

⚠️ 锂电池不要短路、刺穿、过充，必须使用带保护的充电模块。

## 低功耗

估算续航：`续航(h) = 电池容量(mAh) / 平均电流(mA)`。

一块 Uno 空跑约 45mA，2000mAh 电池只能撑 2 天。降低功耗的方法：

1. **睡眠模式**：
   - AVR：`LowPower.powerDown(SLEEP_8S, ...)`（Low-Power 库），电流可降到数 μA（需去掉板载 LED 和 USB 芯片）。
   - ESP32：`esp_deep_sleep_start()`，深度睡眠约 10μA，可用定时器或 GPIO 唤醒。
   - RP2040：`sleep_goto_dormant_until_pin()`。
2. 降低主频，关闭不用的外设（ADC、WiFi、蓝牙）。
3. 传感器用 GPIO 供电，用完就断电。
4. 选择更省电的裸芯片方案，而不是开发板（开发板上的 USB 芯片、电源灯、LDO 都在耗电）。

## 去耦与滤波

- 每个芯片电源脚就近放 100nF 陶瓷电容。
- 电机/舵机电源并联 100 ~ 470μF 电解电容。
- 数字地和大电流地分开走线，最后一点汇合。
