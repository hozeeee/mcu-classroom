## 什么时候需要焊接

- 很多模块（如 Pico、OLED、传感器）出厂时 **排针没有焊上**。
- 作品从面包板转到洞洞板或 PCB。
- 修复断线。

## 工具清单

| 工具 | 建议 |
| --- | --- |
| 电烙铁 | **恒温可调温** 烙铁（如 T12、936 焊台、便携式 TS101），不要买不能调温的"外热式" |
| 烙铁头 | 刀头（K 头）或马蹄头（C 头）最通用 |
| 焊锡丝 | 0.8mm 含松香芯焊锡丝，有铅（63/37）更易焊，无铅更环保 |
| 助焊剂 | 松香或免清洗助焊膏 |
| 烙铁架 + 清洁海绵/铜丝球 | 必备 |
| 吸锡带 / 吸锡器 | 拆焊用 |
| 镊子、斜口钳 | 夹持元件、剪引脚 |
| 第三只手 / 焊接夹 | 固定 PCB |

## 温度

- 有铅焊锡：320 ~ 350℃
- 无铅焊锡：350 ~ 380℃
- 温度过高会烫坏焊盘、氧化烙铁头。

## 焊接五步法

1. **准备**：烙铁头上锡（新烙铁头先镀一层锡），擦干净。
2. **加热**：烙铁头同时接触 **焊盘和引脚**，约 1 秒。
3. **送锡**：把焊锡丝送到焊盘与引脚交界处（不是送到烙铁头上）。
4. **移锡**：焊锡流满焊盘后移开焊锡丝。
5. **移烙铁**：再停留约 0.5 秒后沿引脚方向移开烙铁。

整个过程 2 ~ 4 秒。

## 合格焊点

```
     │ ← 引脚
    ╱│╲
   ╱ │ ╲   ← 光亮的"小火山"形状，包住引脚，覆盖整个焊盘
 ▔▔▔▔▔▔▔▔
```

## 常见缺陷

| 缺陷 | 表现 | 原因 |
| --- | --- | --- |
| 虚焊 | 焊锡呈球状、表面暗淡，引脚可以晃动 | 加热不足，焊锡没有润湿焊盘 |
| 连锡 | 相邻焊点被焊锡连在一起 | 焊锡太多 → 用吸锡带吸掉 |
| 焊锡太少 | 焊盘没有被完全覆盖 | 补焊 |
| 焊盘脱落 | 铜箔翘起 | 温度过高或加热时间过长 |

## 焊接排针的技巧

1. 把排针插在 **面包板** 上，再把模块放上去——面包板就是最好的定位夹具。
2. 先焊 **两端** 各一个引脚固定，检查是否垂直。
3. 再依次焊完其余引脚。

## 焊接后检查

- 目视检查有没有连锡。
- 万用表通断档检查相邻引脚是否短路、VCC 与 GND 是否短路。
- 再上电测试。
